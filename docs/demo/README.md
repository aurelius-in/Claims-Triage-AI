## 🚀 Deployment

### **GitHub Pages:**
1. Upload entire `demo` folder to GitHub repository
2. Enable GitHub Pages in repository settings
3. Set source to `/docs` or root directory
4. Access via `https://username.github.io/repository-name`

### **Static Hosting:**
- **Netlify:** Drag and drop the `demo` folder
- **Vercel:** Connect repository and set build command to none
- **AWS S3:** Upload folder contents to S3 bucket with static hosting
- **Any web server:** Upload folder contents to web root

### **Local Testing:**
```bash
# Serve locally with Python
cd docs/demo
python -m http.server 8000

# Or with Node.js
npx serve .

# Or with PHP
php -S localhost:8000
```
